## 国内特有洞察
1. **IM 是数字员工的"户口所在地"**：第一入口是钉钉/飞书/企微，入通讯录、进群被@、走审批流。谁掌握通讯录谁掌握"编制"。
2. **双备案制合规是硬门槛与护城河**：算法备案+大模型备案（748 款模型备案），2025 起企业内部模型也纳入备案，GB/T 45654-2025 落地。套壳海外模型在企业级市场出局。
3. **私有化/信创需求远超海外**：私有化是独立统计市场；软硬一体机是中国特色交付。
4. **"专家知识服务化"是差异化主线**：客户买的不是工具而是"带经验入职的员工"，本质是把咨询/BPO 产品化——比海外更接近 BPO 替代而非 Copilot 增强。
5. **定价走向对标人力成本/RaaS**：钉钉 AI 差旅 Agent 对标专员薪资、金蝶按行程数收费。国内 SaaS 席位付费意愿低，定价锚在客户 P&L 上。
6. **创业公司窗口收窄**：纯水平平台已是云厂商+IM 巨头战场；存活独立厂商靠 RPA 存量或深垂类 Know-How。

## 市场空白（机会）
1. **跨 IM/跨平台的数字员工"人事系统"**：统一雇佣、考核评测、审计、成本核算层（中立的数字员工 HRM/编制管理）——现无人做。
2. 备案合规即服务（算法自评估/语料规则/安全评估产品化）。
3. **按结果计费的计量与审计基础设施**：RaaS 共识已形成但卡在"结果定价谁来验证"，缺第三方 Agent 产出计量/SLA 验证。
4. **深业务系统写操作的治理层**：现有平台强读弱写；细粒度"操作审批流+回滚+责任认定"是金融/国企放开写权限的前提（HiAgent 持证上岗只是雏形）。
5. **专家知识资产交易市场**：让行业专家把经验封装为可售卖的数字员工技能包并按调用分成的 C2B 市场，国内尚无人做成。
