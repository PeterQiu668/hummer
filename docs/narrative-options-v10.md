# Hummer 叙事决断 v10 — "中国版 Sierra"审判 + 三套全新划时代叙事

> 2026-07-04 · 回应创始人："直接定义为中国版 Sierra 是不是更简单？或者结合中国国情和初创处境，重新给两三套划时代叙事。"
> 与 v9 的关系：v9 的「敢背 KPI」是产品层标签；本文讨论的是公司层叙事（我们是一家什么公司）。两层可以组合。

---

## 1. "中国版 Sierra"审判：投资人听得懂，市场卖不动

**可以用的部分**：对投资人，一句"Sierra 用按结果收费做到百亿美金估值，验证了 outcome-based 的付费意愿；我们把这个模式带进中国、并从客服泛化到全岗位"——作为**佐证**非常好用。

**不能当定位的四个理由**：

1. **客户听不懂**。Sierra 的客户是财富 500 强，中国中型企业老板没听过 Sierra。"中国版 X"是 pitch deck 语言，不是市场语言——标签活在融资会上，死在客户门口。
2. **会被拖进错误的战场**。Sierra 是客服（CX）垂直公司。自我定义为中国版 Sierra，等于宣布参赛中国智能客服——那是智齿/容联/百度客悦加上钉钉企微原生机器人的十年红海，而我们的 beachhead 是招聘（D2）。
3. **Sierra 的模式恰恰是我们不能学的**。调研原文：Sierra 年费 $150K-1.5M、FDE 驻场重交付、高锁定、利润结构存疑。中国没有这个客单价的软件付费能力，而"驻场重交付"正是澜码死亡的路径（D1 已明确拒绝）。**学 Sierra 的定价哲学，不学 Sierra 的交付形态。**
4. **对标封顶**。"中国版 X"的估值天花板 = X 的中国折扣。划时代产品没有一个自称"某国版某某"。

**结论：Sierra 降为融资材料里的一行佐证。公司叙事必须原创。**

---

## 2. 中国国情 × 初创处境：切入的四条铁律

1. **中国企业不为软件付费，为结果和人力替代付费**（调研洞察 5：定价锚在客户 P&L 上）→ 初创公司最快的路不是卖平台，是**直接卖结果**。
2. **工作发生在 IM 里**（洞察 1：通讯录即编制）→ 产品以群成员形态进入客户，不要求客户学新软件。
3. **叙事必须站在社会正面**。"数字员工"在中国语境天然触碰"抢饭碗"敏感神经 → 划时代叙事必须是"**让请不起人的老板请得起团队**"，而不是"替代你的员工"。给小微企业扩能是政策顺风，替代就业是政策逆风。
4. **初创不打平台战争**（HiClaw/WorkBuddy 免费送执行层）→ 起步阶段所有平台野心都收进"账本和信任资产"这个后手，前台只做一件能收钱的事。

## 3. 三套全新叙事方案

### 方案一 「AI 原生劳务公司」— 我们不卖软件，卖干完的活

**标签句**：把 JD 发过来，三天后收到面的候选人。**我们不是软件公司，是第一家全员数字员工的劳务公司。**
**判死刑**：判"企业软件"死刑——客户不买工具、不学平台、不管 agent，只验收结果、按结果付钱。
**中国国情适配**：完美贴合"为人力替代付费"的付费心智（对标猎头费 20-25% 年薪，我们按到面 ¥100-300/人，价格是猎头的 1/10）；外包心智全民成熟；客户零学习成本（结果直接进他的企微群）。
**初创切入**：GTM 倒置——亚马逊先自己用 AWS 再开放。我们先做"劳务公司"用自己的平台交付（M1-M2 第 0 号客户=自己 HR，D8 原文），现金流第一天为正；跑通 3-5 个 KPI 品类后，平台作为"劳务公司的内部系统"已被真实业务淬炼过，再开放给客户自雇（Phase 2 变奏）。
**终局**：AI 原生 BPO 吃掉传统外包行业（中国 BPO 万亿市场），平台随后开放。
**风险与对策**：① 看起来像服务公司估值低 → AI 边际成本结构 + 后手平台化讲清即可（Sierra 就是证据）；② 滑向项目制定制（澜码之戒）→ 铁律：只卖标准化 KPI SKU（到面数/合格线索数），拒绝一切定制需求单。

### 方案二 「一个人的公司」— 让每个老板都开得起一家"大公司"

**标签句**：一个人 + 一支数字军团 = 一家完整公司。**让中国 1.2 亿小老板，第一次请得起一个团队。**
**判死刑**：判"雇不起人"死刑——招人难、养人贵、留人累，从此不是开公司的门槛。
**中国国情适配**：个体工商户 + 小微企业 1.2 亿主体，是全球最大的"请不起人"人群；"超级个体"叙事正热；社会正面性拉满（扩能弱者而非替代员工）——这是三案中唯一能上主流媒体正面报道的叙事。
**初创切入**：自下而上，OpenClaw/Hermes 式病毒路径的企业版——低价套餐（初创版 ¥8,800/月已有）+ 军令状海报圈层传播 + 抖音/视频号"老板日记"内容营销（"我公司就我一个人，上个月营收 XX"）。
**终局**：公司形态的重新定义——未来注册一家公司，像今天注册一个微信号。
**风险与对策**：① 客单价低、服务成本高、churn 高（SMB 的永恒难题）→ 必须极致自助 + 毛利红线死守（模型分层路由 P0）；② 与当前 50-1000 人中型企业定位（D2 客群）冲突 → 若选此案，beachhead 客群要下移重议；③ 小老板需求碎（什么都要一点）与"窄 KPI 纪律"冲突 → 起步只给三个标准岗位（获客/接待/记账助理），拒绝自由定制。

### 方案三 「数字员工的人才市场」— 我们不生产员工，我们是员工的市场和信用体系

**标签句**：全中国的行业专家在这里把经验做成数字员工，全中国的企业在这里**按达成率**挑员工。**每个员工带证上岗、达成率公示、出错平台赔。**
**判死刑**：判"AI 黑箱用工"死刑——用 AI 干活从此像招人一样：看简历（认证分）、看业绩（达成率）、有保险（赔付）。
**中国国情适配**：直接落在调研的两个国内空白上（⑤专家知识资产交易市场、①跨平台数字员工人事系统）；"出错平台赔"比 v9 的"退费"更进一步，是中国客户最认的信任语言（参考运费险/职业责任险心智）；供给侧激活行业专家（下岗的中层、退休的老师傅把 know-how 变现）——这是唯一同时解决"AI 替代焦虑"供给侧的叙事，社会意义最深。
**初创切入**：双边市场冷启动是初创最难路径 → 必须先用方案一/二攒下需求侧和首批自营"员工"，专家生态 Phase 3 再开（架构文档风险 1 原文：先自营冒充供给）。
**终局**：AI 劳动力市场的"人社局 + 芝麻信用 + 平安保险"——平台终局最大，护城河最深（信用资产 + 双边网络）。
**风险与对策**：① 第一天讲市场故事而无供给 = 空壳 → 只能作为终局叙事，不能作为切入叙事；② 赔付承诺需要精算与保险合作 → Phase 2 起步用"退费"，Phase 3 引入责任险合作方升级为"赔付"。

## 4. 推荐组合：三段火箭（三案不是单选题，是时间顺序）

```
第一级（0-12 个月）  方案一 · AI 原生劳务公司
                    「把 JD 发过来，三天后收到面的候选人」
                    现金流为正 · 平台被真实业务淬炼 · 攒达成率数据
                         ↓ 达成率数据 + 标准化 KPI SKU 成熟
第二级（12-30 个月） 平台开放 + 方案二人群下探
                    「敢背 KPI 的数字员工」(v9 标签在此接管产品层)
                    客户自雇 · 军令状病毒传播 · 岗位品类扩张
                         ↓ 需求侧规模 + 信任账本沉淀
第三级（30 个月+）   方案三 · 数字员工的人才市场
                    专家共创供给侧开闸 · 认证/达成率/保险三件套
                    终局：AI 劳动力的信用基础设施
```

**如果今天只能对外说一句话**（融资和获客通用）：

> **「我们把猎头这件事的价格打到了十分之一——不是用更便宜的人，是用带证上岗、完不成不收钱的数字员工。这只是第一个岗位。」**

具体（猎头 1/10 价格）+ 结果（到面付费）+ 机制暗示（带证/退费=信任基建）+ 野心钩子（第一个岗位）——四层各自钩住客户、老板、投资人和团队。

**与既有决策的兼容性**：D1-D8 全部无需推翻——方案一就是 D5/D8 的叙事升维（把"HR beachhead 的定价方式"升格为"公司是什么"）；v9 的「敢背 KPI」在第二级接管产品层标签；v8 的账本/信任层是第三级的地基。唯一新增决策点：**对外自称"劳务/人力公司"还是"科技公司"**——建议工商与融资层面是科技公司，市场传播层面用劳务公司的语言（"发 JD 收候选人"），语言即定位。
