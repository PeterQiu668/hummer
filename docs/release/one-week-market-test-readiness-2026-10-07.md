# HUMMER 一周市场测试就绪度结论（2026-10-07）

## 一句话结论

一个人一周可以把 HUMMER 推到**受监督的封闭市场测试**，但不能在一周内做成“统一管理所有 Agent 的完整平台”。本周应卖的不是 Agent 数量或组织图，而是一个窄闭环：**从一个入口向一台受控节点派一个明确任务，人批准，执行一次受限动作，返回可独立校验的回执。**

## 已经具备的可测底座

- Desktop/Web 与同一 Relay 的派活、批准、拒绝、停止；
- Relay/Node 常驻进程、SQLite 持久状态、事务性 Desktop outbox；
- 审批撤销、超时、一次性 task grant、批准后动态 bearer 签发；
- Node 启动只需 badge，不存在静态任务令牌回退；
- 唯一开放的真实执行器 `fs.read.attest.v1`：只读一个显式相对路径，输出字节数和 SHA-256，不返回正文；
- 本机 `run/status/stop` supervisor：临时凭证只在内存，配置和状态不含 secret；
- 证据链最新 rootHash：`f12897dd70173ea9c2f56f168f792e12696165815ce716aed4f63d9ee692465b`。

最新封存轮的 6 条命令全部退出 0；真实 stack 门为 30 条断言，Relay 为 209/209，root unit/UI、typecheck/build 全绿。实现 HEAD 为 `ac19793`，未推送、未部署、未修改网络/证书/防火墙、未接支付、未修改 `F:\agent-hub`。

## 一周内不能诚实承诺的事

- 零配置首次安装：local stack 仍需要精确绑定一个已存在的 Desktop tenant/account；
- 真正多机：目前权威证据仍是单 Windows 主机 loopback；
- 生产安全：没有私有 TLS、外部 IdP、KMS/HSM、issuer key 轮换和代码签名；
- 通用 Agent 执行：Codex/Claude/Shell、网络、写入、付款、删除和提权仍关闭；
- 专家蒸馏与能力市场：本地内核和产品表面不等于真实专家 5 次 shadow、第三方安装或付费信号；
- “炉子/Paperclip/Muse 的完整统一编排平台”：这不是一周范围，也不是当前最小市场假设。

## 建议的 7 天市场验证冲刺

| 天 | 唯一目标 | 通过证据 | 停止条件 |
|---|---|---|---|
| D1 | 在第二台干净 Windows 上完成受信安装与身份绑定 | 15 分钟内装成；安装日志与回滚记录 | 无法在 30 分钟内由非开发者完成 |
| D2 | 私有 TLS Relay 连通 Desktop 与第二台 Node | 真实跨机心跳、断线、重连与 badge 过期负例 | 需要改防火墙/证书但未获 L3 批准 |
| D3 | 1 位真实专家完成 1 个只读证明任务 | 人工批准、一次执行、独立回执验证 | 仍需开发者手工改库或复制 token |
| D4 | 同一任务做 5 次 shadow | 5 次唯一 run、失败点与环境指纹 | 成功率低于 4/5 或证据不绑定 |
| D5 | 修复阻断问题，不扩执行面 | 阻断问题清零、回归全绿 | 修复要求开放通用 Shell/网络 |
| D6 | 3–5 位种子用户各完成 1 个任务 | 安装率、首任务时间、审批理解度 | 少于 2 人独立装成或完成 |
| D7 | 访谈与 go/no-go | 复用意愿、愿付价格、下一任务承诺 | 用户只要状态看板，不在乎派活/回执 |

D1–D4 涉及真实第二台设备、私有 TLS/证书、安装和专家数据，必须先按 L3 清单取得丘总确认；未确认前只能准备方案，不能执行。

## Go / no-go 指标

继续投入必须同时满足：

1. 至少 2/5 非开发者能独立安装并完成首任务；
2. 首任务从打开安装包到可验证回执不超过 30 分钟，目标 15 分钟；
3. 5 次 shadow 至少 4 次成功，且每次都有不同 run 与真实证据；
4. 至少 2 位用户明确表示会再次使用“统一派活 + 审批 + 回执”，不是只想看状态；
5. 至少 1 位用户愿意进入付费试点讨论，并能说出愿付费的具体风险或成本。

任一核心指标失败，就停止扩平台，把 HUMMER 收敛为内部可信交付台/开源证据组件；不要用更多 Agent 适配、3D 界面或能力市场功能掩盖需求不足。

## 当前推荐决策

**Go，但只批准 7 天封闭证据冲刺，不批准一年期统一编排平台建设。** 技术风险已经从“能不能做”下降到“外部用户是否愿意安装、理解审批并为可验证交付付费”。下一笔开发时间必须买外部证据，而不是继续买本机功能。
