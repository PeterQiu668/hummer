# Hummer 定位决断 v9 — 五个维度、一个标签、一条实现路径

> 2026-07-04 · 回应创始人质询："WorkCommit 用户价值不深，用户只为结果买单。划时代 = 结果导向 + 解决企业/社会问题。给我 3-5 个维度的重新分析，和唯一的那个标签。"
> 本文修正 v8 的定位重心：账本/WorkCommit 降为**隐形基建**（裁判所），标签必须是结果语言。

---

## 0. 一个前提共识：划时代产品的标签公式

回看所有划时代产品的标签，没有一个是"能力描述"，全部是**结果承诺 + 旧世界的死刑判决**：

- iPhone："重新发明手机"（判了键盘机死刑）
- 拼多多："3 亿人都在拼"（判了"网购是中产行为"死刑）
- OpenClaw："会干活，不只会聊天"（判了 chatbot 死刑）
- Hermes："越用越强"（判了"每次对话从零开始"死刑）

所以 Hummer 的标签必须回答：**我们承诺什么结果？我们判了什么东西的死刑？**

---

## 1. 五个维度重审：亮点、突破点、能否成为"唯一标签"

### 维度一：结果 — 敢背 KPI，完不成不收钱 ★推荐为唯一标签★

**用户价值**：老板雇人的终极痛苦不是工资，是**不确定性**——招人难、养人贵、管人累、走了带走经验，而且付了工资不保证有产出。全世界的雇佣合同都是"买时间"，没有任何员工（真人或数字）敢签"买结果"。**第一个敢背 KPI 的数字员工，判的是"买时间"这个五千年雇佣制度的死刑。** 这就是社会级问题的答案，这就是划时代。

**为什么只有我们做得到（突破点）**：敢按结果收费的前提是**结果可验证**——到面了没有、初筛准不准、客户回复了没有。验收工作台 + 证据链 + 审计账本 + 账单归因，这套别人没有的基建恰好组成"结果裁判所"。海外唯一先例 Sierra（解决才收费）年费 $150 万还被抢着买，证明付费意愿存在；国内 RaaS 共识已形成但全部卡在"结果谁来验证"（调研空白 #3）——**我们卡位的就是裁判所本身**。WorkCommit 没有被浪费，它从卖点退役为承诺的公证人。

**风险与纪律**：这是精算生意不是口号生意。① 只承诺**窄口径、可验证、agent 可控**的 KPI（到面数、初筛通过率、合格线索数），绝不承诺营收类 KPI（归因不清 + 法律风险）；② 承诺区间制（保底 X / 目标 Y），未达标梯度退费而非全额退；③ 试岗期就是精算期（见 §3）。

### 维度二：信任 — 智能判责，默认自治，需要人时才拉人

（创始人例一"第一个 AGI 企业 agent"的正确打开方式）

**用户价值**：现有企业 agent 全是"事事请示"的实习生，审批洪水让老板比没雇它还累。反转范式：**默认放手干，agent 自己判断什么时候需要人**——需要担责时拉担责人、需要决策时拉决策人、其余时间安静干活。老板的管理成本趋近于零。

**突破点**：任务受理器（复杂度评级）+ 担责判定引擎（commandPath）+ 自治度旋钮 + 连续验收自动升档——Phase 0.5 已规划的四个机制，合起来就是"智能判责"，没有对手把这四件事连成一个闭环。

**为什么不能当唯一标签**：①"AGI"字样 2026 年已审美疲劳且触发采购合规警觉；② 这是能力承诺，一次重大事故就击穿（架构文档风险 #3）；③ 它是"KPI 达成的效率手段"，是**how** 不是 **what**。降为支柱，对外话术："它知道什么时候该找你——其余时间，它在干活。"

### 维度三：能力 — 真实执行的数字员工军团

（创始人例二"史上最强军团、每个都能直接干活"）

**用户价值**：真实干活（桌面执行 + 工具调用 + IM 触达客户）当然是地基——不能干活一切归零。

**为什么不能当唯一标签**：执行能力正在被免费商品化——OpenClaw 开源、Hermes 开源、WorkBuddy 腾讯捆绑、HiClaw 阿里开源。**在别人免费送的维度上称"史上最强"，等于在自助餐厅门口卖白米饭。** 且"最强"是不可验证的形容词，采购不为形容词付钱。"军团"作为视觉语言保留（3D 演示模式里军团列阵很有传播力），作为定位放弃。

### 维度四：成长 — 自我进化，永不离职，越用越强

（创始人例三，Hermes 基因的企业版）

**用户价值**：中小企业最深的隐痛之一：**人走了，经验跟着走**。数字员工反过来——每次失败复盘进 SOP，每次验收沉淀成 know-how，公司的经验第一次变成**留得下来的资产**。"这个月没达标？它自己复盘，下个月更强，而且永远不会辞职去竞争对手那里。"

**突破点**：质量飞轮（bad case → 归因 → SOP 灰度升级 → 全岗位同步）+ 知识回流，已在支柱二/五设计。Hermes 证明"自进化"叙事有病毒力。

**为什么不当唯一标签（但是最佳副标签）**：自进化描述的是**斜率**，不回答"现在雇它我得到什么"。老板先要结果，再要复利。它是标签的第二句话："**这个月的 KPI 它背，明年的它更背得动。**"

### 维度五：经济 — 确定性成本，透明 ROI

**用户价值**：事前知道花多少钱（预算硬顶）、失败不计费、月度 ROI 报告。全行业头号抱怨（成本黑箱）的直接解药。

**为什么不当唯一标签**："省钱"和"可控"是卫生指标，能防流失、不能造惊叹。它自然折叠进维度一——"完不成不收钱"本身就是最强的成本确定性。

## 2. 决断：唯一标签

> ## **「第一个敢背 KPI 的数字员工」**
> ### 合同钩子：完不成，不收钱。
> ### 副标签（斜率承诺）：这个月的 KPI 它背，明年它更背得动。

一句话哲学（对外演讲版）：**工业时代企业买时间，AI 时代企业买结果。Hummer 判"买时间"死刑。**

五维度在标签下的队形：

```
        「第一个敢背 KPI 的数字员工」        ← 标签（结果维度）
       /            |             \
  智能判责响应快   真实执行干得动    自我进化越背越多   ← 三大支柱（信任/能力/成长）
       \            |             /
        结果裁判所：验收+证据+账本+结算       ← 隐形基建（WorkCommit 的归宿）
        完不成不收钱 = 成本确定性            ← 经济维度（折叠进承诺）
```

对创始人三个候选的裁决：**"AGI 企业 agent"** —— 实质保留（默认自治 + 智能判责），字面放弃（合规与事故风险）；**"史上最强军团"** —— 视觉保留（演示模式），定位放弃（商品化维度）；**"自我进化"** —— 升为副标签（斜率承诺）。

## 3. 如何实现：从标签到产品的六步

### 第一步 · KPI 报价单（市场页的灵魂手术）
员工市场从"功能橱窗"改为 **KPI 橱窗**：每个数字员工卡片 = 我承诺的 KPI（口径+区间）+ 我的历史达成率（公开！全行业没人敢公示成功率——调研空白 #4，我们做成首页）+ 完不成怎么办（梯度退费条款）+ 单价。
`Marketplace.tsx` 改造：卡片主视觉从头像+技能改为 **KPI 数字 + 达成率**。

### 第二步 · 试岗期重新定义为"KPI 校准期"（剧场变真需求的范例）
7 天试岗不再是拟人仪式，而是**精算过程**：用客户真实数据跑出 KPI 基线 → 试岗报告卡输出"我敢承诺的区间" → 转正 = 签军令状。v8 批评的"拟人日历剧场"由此转正为核心商业流程。
`TrialReportCard.tsx`：四维指标改为"承诺区间生成器"。

### 第三步 · 军令状仪式（授权仪式 × 传播物）
转正签署页升级：权限/额度/有效期之外，增加 **KPI 军令状**——本月目标、结算单价、未达标退费条款，生成一张可转发的军令状海报（老板会发朋友圈/老板群，中国 B2B 病毒回路）。
`AuthorizationCeremony.tsx` + 新增分享卡片组件。

### 第四步 · 结算即验收（账本兑现承诺）
计费事件 = 验收通过事件（到面 1 人 = ¥X 入账，证据链附带）。ROI 页改名 **「KPI 结算单」**：本月承诺/实际/结算额/退费额，每行可展开证据。D8 定价决策（岗位订阅 ¥2-4k + 按到面 ¥100-300/人）已经是这个模式——**把它从定价细节升格为品牌本身。**
`RoiPage.tsx` 重构。

### 第五步 · 智能判责作为达成率的引擎（支柱就位）
Phase 0.5 P0 的任务受理器 + 责任链 v2 照做，但叙事反转：不是"人管 agent"，而是 **"agent 知道什么时候找人"**——找人是为了 KPI 不落空（卡住 2 小时自动升级、需担责动作精准拉人）。收件箱事件全部重写为 KPI 语言："这件事不处理，本月到面数预计 -2。"

### 第六步 · 北极星与组织对齐
北极星指标从 WAD 升级为 **KPI 达成率 ×续约率**。所有 feature 过两个过滤器：①提高达成率吗？②提高结算可信度吗？都不提高的不做。演示脚本重写为一条线：看 KPI 报价 → 试岗校准 → 签军令状 → 干活(自治+拉人) → 验收结算 → 未达标退费 → 复盘进化下月更强。

### Beachhead 完全兼容（D2 不动）
HR 寻访/初筛就是标签的第一个宿主：到面 = 全世界最干净的可验证 KPI 事件，猎头费 = 全世界最成熟的按结果付费心智。创始人例子里的"HR 结合招聘软件自动招聘"= D5 原文；"市场员工聊客户背 KPI"= 第二个岗位（SDR，合格会议数），Phase 2 扩展。

## 4. 风险清单（标签的代价）

1. **精算失败 = 亏钱**：达成率虚高承诺会直接退费亏损 → 试岗校准纪律 + 承诺区间保守起步 + 前 10 家客户人工盯盘。
2. **窄 KPI 被质疑"就这？"**：到面数看起来小 → 用"敢公示达成率"对冲（诚实即高级），逐季扩 KPI 品类。
3. **对手抄标签**：钉钉/腾讯明天也可以说"背 KPI" → 他们没有结果裁判所（验收+证据+账本），抄了标签兑现不了退费，反而帮我们教育市场。裁判所基建是标签的护城河——这就是 v8 的 WorkCommit 与本文的和解。
4. **法律**：退费条款、KPI 定义、数据处理（PIPL）→ D7 法务清单增加"军令状合同模板"。
